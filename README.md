# CLUTCH — Performance OS

A lightweight, local-first productivity MVP designed around one principle:

**Decide → Start → Focus → Finish → Recover → Repeat**

## Run it

Open `index.html` directly in a browser, or use VS Code Live Server.

No backend or dependencies are required.

## Included

- One-action home screen
- Study / Build / Train / Recover / Shutdown flows
- Clutch focus timer
- Left-column distraction parking
- Recovery timer
- Daily shutdown
- LocalStorage stats
- Responsive mobile/desktop UI
